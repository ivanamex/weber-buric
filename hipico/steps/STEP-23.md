# STEP-23: "Confirmar clase" for classes in the plan

Wording: "reservar" sounds like holding a spot that isn't paid yet. A class taken from the plan is already paid, so it's **confirmed**.

- On the **Plan activo** card: "Reservar clase" → **"Confirmar clase"** (keep it as a button next to "Cambiar plan"; if it doesn't fit on 360 px, "Cambiar plan" becomes a text link under the card).
- The same words through the whole flow: the slot button says **Confirmar**, the toast says **"Clase confirmada · te quedan 2"**, the list shows **Confirmada**, and cancelling says **"Cancelar clase"**.
- Only single / trial / extra classes (paid separately) keep the word **"Reservar"** with the price, e.g. "Reservar clase suelta ($Y)".
- The bottom tab "Reservar" → **"Clases"**.
- English: "Confirm class" / "Class confirmed" / "Classes".
