# Install + sign-in test (iPhone and Android)

Do it with the right glasses, on a real iPhone and a real Android (borrow one). Tick each line. Screenshot anything odd.

## iPhone (Safari)
- [ ] Send yourself the link on WhatsApp, tap it: the page says "Abre este enlace en Safari" + Copiar enlace
- [ ] Open it in Safari: the **Descargar para iPhone** button is highlighted
- [ ] Tap it: the 2-step guide shows, and the arrow points at the Share button
- [ ] Share → Añadir a pantalla de inicio: the icon is the club logo on green
- [ ] Open the icon: it opens full screen, with no Safari bar
- [ ] Sign in inside the icon (code, or "Ya tengo contraseña")
- [ ] Close the app completely, reopen it: still signed in
- [ ] Next day, reopen it: still signed in

## Android (Chrome)
- [ ] Open the link from WhatsApp: it's offered to open in Chrome
- [ ] **Descargar para Android** is highlighted, and tapping it shows the install dialog (one tap)
- [ ] The icon on the home screen is the club logo
- [ ] Sign in inside the app, close it, reopen it: still signed in
